1. Make a variable called mypython that contains the path to Python on your machine. You shouldn’t need to manually type the path.

mypython=$(which python)  # create variable with the path
echo $mypython            # print value of variable (i.e., the path)
/home/kathe/opt/miniforge3/bin/python

2. Construct a variable that has the value <username>@<machinename> using existing environment variables and the hostname utility.

I wasn’t sure if the question intended the value in the variable to include the less-than and greater-than symbols, so I solved the problem both ways. (My laptop’s name is “tris” after the character Tris in Divergent. Don’t judge me!)

Excluding the less-than and greater-than symbols:

ghost_in_the_machine="$(whoami)@$(hostname)"    # create variable 
echo $ghost_in_the_machine                      # print value of variable
kathe@tris

Including the less-than and greater-than symbols:

ghost_in_the_machine="<$(whoami)>@<$(hostname)>"    # create variable 
echo $ghost_in_the_machine                          # print value of variable
<kathe>@<tris>

4. How would you count the number of lines in an input file, say, a data file?

This code presumes a file exists titled datafile.txt in the current working directory. I invented one with the following contents. (The seventh line has commas for later use in problem 9.)

Code to count the lines:

wc -l datafile.txt    # -l modifier tells the wc function to count the number of new lines

5. Print the first three lines of a file to the screen. Now print just the third line to the screen.

Using the same file, the first three lines:

head -n 3 datafile.txt
1 kitten 62234 26342
2 puppy 62314 26212
3 piglet 23314 92312

Third line only:

sed -n '3p' datafile.txt
3 piglet 23314 92312

6. Put the third line of a file in a new file.

sed -n '3p' datafile.txt > newfile.txt    # put the third line into a new file
cat newfile.txt                           # print new file to prove that it worked
3 piglet 23314 92312

7. Now add the fifth line of the file to that same file from the previous problem.

sed -n '5p' datafile.txt >> newfile.txt    # add fifth line to the prior file
cat newfile.txt                            # print new file to prove that it worked
3 piglet 23314 92312
5 foal 82344 42312

10. Write shell code that creates files file1.txt, file2.txt, file3.txt, etc., with the word ‘blah’ as the only line in each file.

n_of_files=3                    # to change the # of files, change this value
for(( n=1; n<=$n_of_files; n++))          
do
    echo "blah" > file$n.txt    # create each numbered file and its blasé content
    ls -l "file$n.txt"          # print info about each file to prove that each exists
    cat file$n.txt              # print contents of each file to prove its indifference
done
