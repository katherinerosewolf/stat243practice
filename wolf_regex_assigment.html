1. Match the strings “dog”, “Dog”, “dOg”, “doG”, “DOg”, etc. (The word ‘dog’ in any combination of lower and upper case.)

Create a list of all the strings to catch (and some not to catch):

cat > to_heaven.txt  # create a new text file

# add words to catch to the text file
for word in "dog" "doG" "dOg" "dOG" "Dog" "DoG" "DOg" "DOG"; do
echo $word >> to_heaven.txt
done

# add words we don't want to catch to the text file
for word in "cat" "c@t" "dOog"; do  
echo $word >> to_heaven.txt
done

cat to_heaven.txt  # print contents of said text file

doG
dOg

Dog

DOG

Solution that apples the regular expression (D|d)(O|o)(G|g) (in extended syntax to use the metacharacters ( and )) to the list of strings and display the results:

echo "results of solution using grouping and or, i.e., |, symbol" 
grep -o -E '(D|d)(O|o)(G|g)' to_heaven.txt

4. Match two words separated by any amount of whitespace.

Create a test file from the opening of Mrs. Dalloway (1925) by Virginia Woolf with random tabs and spaces between words:

cat > mrs_dalloway.txt  # make the new document

echo "Mrs.   Dalloway said    she would buy  the  flowers herself." >> mrs_dalloway.txt
echo "For Lucy had her work     cut     out for her." >> mrs_dalloway.txt 
echo "The doors would be  taken off their hinges;   Rumpelmayer's men..." >> mrs_dalloway.txt

cat mrs_dalloway.txt  # print the test file
Mrs.   Dalloway said    she would buy  the  flowers herself.
For Lucy had her work     cut     out for her.
The doors would be  taken off their hinges;   Rumpelmayer's men...

This solution code below defines two functions, one that uses grep and an extended regular expression to match word pairs and any number of spaces or tabs between (but misses every other possible pair), and another that uses sed and another regular expression to remove the initial word and any amount of space at the beginning of each line of a file and feeds the result into the first function to output the other half of the consecutive word pairs. It does, however, define everything that isn’t in the "space" class as a word.

# function that grabs word pairs (but misses every other pair):
grab_spacious_pairs () { 
  grep -Eo '[^[:space:]]+[[:space:]]+[^[:space:]]+' $1 
  }

# function that grabs all word pairs:
grab_all_spacious_pairs () {
  # matches half the word pairs
  grab_spacious_pairs $1  
  # deletes first word and any spaces after to match the other word pairs
  sed 's/^[^[:space:]]*[[:space:]]\+//' $1 | grab_spacious_pairs
  }
